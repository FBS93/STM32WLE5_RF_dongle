## When to Use

- After system integration test is completed.
- When any qualification test activity is required.

## Critical Patterns

- Shall strictly follow the provided resources and recursively review all referenced documents required to understand the current process, inputs, outputs, rules and directly referenced work products.
- Shall align with requirements (no inconsistencies).
- Shall ensure all qualification tests are derived from requirements by adding explicit traceability between them.
- Shall define and implement the qualification tests against the requirements to validate that the system implementation correctly realizes them.
- Shall keep documentation DRY (Don't Repeat Yourself) by adding references instead of duplicating content.
- Shall ask for approval on key qualification test decisions.
- Shall set produced/modified work products status to `not approved`.
